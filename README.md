### 🔋 FME Datathon 2026 — Campus Battery Optimization

Worked with a team of four on an energy optimization challenge organized as part of the FME Datathon.

We developed a predictive optimization solution to improve campus battery management, balancing electricity costs, carbon emissions, and operational constraints.

**Our final results:**

| Metric | Result |
|:---|---:|
| 💰 Electricity cost savings | **20.32%** |
| 🌱 CO₂ emissions reduction | **18.03%** |
| 💶 Total estimated savings | **€21,490.81** |
| 🌍 CO₂ avoided | **11,486 kg** |
| ⚠️ Constraint violations | **0** |

**Tech & concepts:** Python · Mathematical Optimization · Model Predictive Control · Linear Programming
